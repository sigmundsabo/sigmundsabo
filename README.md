## Projects

**[Calyze](https://github.com/sigmundsabo/calyze-data)**
An analytics platform that doesn't try to predict prices, it measures how predictable they are in the first place. Every forecast is fingerprinted and published before the outcome is known, so the results can't be edited afterwards. The app is private, the measurement pipeline is public.
`Python` `TypeScript` `Supabase` `GitHub Actions`

**[Flint](https://github.com/sigmundsabo/flint)**
Habit and health tracker for a small group of friends: daily habits, health metrics, workout log and streaks. Installable web app with row-level security on every table.
`React` `TypeScript` `Supabase` `PWA`

**[FORGE](https://github.com/sigmundsabo/forge-split-tracker)**
Workout split tracker built for the phone: sets, reps, rest timer, personal records. No server, works offline. [Live demo](https://forge-split-tracker.netlify.app)
`JavaScript` `PWA` `Playwright`

**[Pablo](https://github.com/sigmundsabo/pablo)**
The card game Pablo, written in Python with pygame. My first real Python project.
`Python` `pygame`
